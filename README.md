# 🧮 Web-Based Calculator

A simple, responsive calculator built using HTML, CSS, and JavaScript — performs basic arithmetic operations right in the browser.

## ✨ Features

- Addition, subtraction, multiplication, and division
- Clean, responsive UI that works on both desktop and mobile
- Clear/reset functionality
- Keyboard and click support

## 🛠️ Built With

- **HTML** – structure
- **CSS** – styling
- **JavaScript** – calculator logic
